# Echo — Music Website

A responsive single-page music discovery website built with HTML5, CSS3, JavaScript and Bootstrap 5.

## Run locally
1. Extract the ZIP folder.
2. Keep the `audio`, `images`, `css`, and `js` folders alongside `index.html`.
3. Open `index.html` in a modern browser. For best results, use VS Code Live Server.

Bootstrap, Bootstrap Icons and Google Fonts use CDNs, so an internet connection is needed for those assets. Audio tracks and song cover images are stored locally. The featured Karan Aujla portrait is loaded from Rolling Stone India and requires an internet connection.

## Included features
- 10 song cards with cover art
- Search songs/artists and filter by mood
- Play/pause, next/previous, shuffle, repeat, seek and volume controls
- Now Playing panel and persistent bottom player
- Responsive layout and light/dark theme toggle
- Featured artist profile for Karan Aujla with biography highlights and source links
- Styled About Echo section and responsive contact section
- Contact form with name, email and comments validation (does not send email or store submissions)
